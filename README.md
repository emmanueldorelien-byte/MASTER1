# AI Masterclass Konsole

Create a modern, stunning, and highly engaging web application in Haitian Creole for an online AI training workshop ("Masterclass AI: Kreye Kontni & Fè Aplikasyon"). The app must feature a high-tech, futuristic theme with dark mode aesthetics (deep dark purple/blue background, neon cyan, glowing purple, and bright accents).

### Key Pages & Features:

1. Hero Section & Landing Page:

- Eye-catching hero section with a glowing title: "MASTERCLASS AI: Kreye Kontni & Fè Aplikasyon!"

- Highlights: "100% Gratis", "Live sou YouTube", "Certificat de Participation Included".

- A live countdown timer set for Sunday, August 30, 2026, at 10:00 PM (Haiti Time).

- Course Content Overview cards:

  - Kreyasyon Kontni: Generasyon tèks, imaj, ak lide ak zouti AI.

  - Kreyasyon Aplikasyon: Kijan pou w sèvi ak AI pou w kòde epi kreye aplikasyon fasilman.

  - Pwodiktivite ak Automatisation.

2. Limited Registration Form (Max 200 Spots):

- Form fields: Full Name, Email Address, WhatsApp Phone Number, and Preferred Certificate Language (Haitian Creole, French, Spanish, or English).

- Dynamic Registration Counter displaying remaining spots (e.g., "Sèlman 200 plas disponib! Plas ki rete: X").

- Interactive toast notifications when users submit successfully.

3. Live Stream & Content Hub Page:

- Embedded YouTube Live video player placeholder.

- Downloadable resource links section for attendees (PDFs, prompts, code snippets).

4. Automated Multilingual Certificate Generator (Core Feature):

- A dedicated tab/page where registered users can generate and download their certificate after completing the course.

- Certificate Customizer Preview allowing the user to select the language:

  - Haitian Creole: "Sètifika Patisipasyon"

  - French: "Certificat de Participation"

  - Spanish: "Certificado de Participación"

  - English: "Certificate of Participation"

- The certificate template must look professional, elegant, and official (with golden borders, dynamic user name, issue date, unique verification ID, and downloadable as PDF/Image or printable).

5. UI/UX Style Guidelines:

- Clean typography, smooth scroll animations, glassmorphism card effects, and responsive layout for mobile and desktop.

- Default UI text in clear Haitian Creole.
